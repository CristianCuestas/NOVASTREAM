NOVASTREAMS


Descripción del proyecto
NOVASTREAM es una página web y aplicación que recopila los datos de las aplicaciones de streaming que existen hoy. Este documento explica, de forma conceptual, cómo damos el desarrollo de los aplicativos de HTML y CSS, proyecto que se desarrolla aplicando los conocimientos adquiridos durante el primer semestre en las materias de Introducción a la Programación, Lógica de Programación y Metodologías Ágiles.


Introducción a la Programación
Esta materia nos aporto los conocimientos necesarios para construir la estructura y presentación visual de NovaStreams mediante HTML y CSS.
En el proyecto aplicamos estos conocimientos:
- HTML: estructura de las páginas, encabezados, menús, secciones, tarjetas, botones y pie de página.
- CSS: colores, fuentes, fondos, bordes, sombras y organización de los elementos.
- Flexbox: distribución y alineación de los elementos de la interfaz.
- CSS Grid: organización de las tarjetas de términos y condiciones.
- Media Queries: adaptación de las páginas a diferentes tamaños de pantalla.
- Pseudo-clases y pseudo-elementos: incorporación de efectos visuales e interacciones.
- Tailwind CSS: utilización de clases de utilidad para complementar el diseño y la presentación de los elementos.

Lógica de Programación 
Esta materia nos permitio desarrollar el pensamiento lógico y la capacidad de organizar instrucciones para resolver problemas mediante algoritmos.
Durante el semestre trabajamos en PSeInt conceptos como:
- Variables y tipos de datos.
- Condicionales.
- Ciclos Para.
- Ciclos Mientras.
- Contadores y acumuladores.
- Vectores y recorridos.

Estos conocimientos nos permitieron comprender cómo se organizan los procesos y las decisiones que podemos realizar cuando tenemos el desarrollo como tal de cualquier situacion presentada frente a un proyecto.

Metodologías Ágiles
Esta materia nos aporto en la organización y planificación del trabajo en equipo para desarrollo de todos los trabajos de NovaStreams de manera ordenada y colaborativa.
Durante el desarrollo del proyecto uyilizamos diferentes conceptos y herramientas tales como:
- Planning: reunión para planificar las actividades y definir el trabajo de cada integrante 
- Daily: seguimiento de las actividades realizadas, los avances y las dificultades.
- Retrospective: espacio para analizar el trabajo del equipo e identificar oportunidades de mejora.
- Historias de usuario: descripción de las necesidades y acciones de los diferentes usuarios.
- Criterios de aceptación: condiciones que permiten comprobar si una historia de usuario cumple con lo solicitado.
